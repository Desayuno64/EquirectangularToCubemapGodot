# EquirectangularToCubemapGodot
Basic Blender set up scene to convert any panoramic image into godots standard cubemap 2x3


To use it, navigate to the world panel, add your panorama as an enviroment texture, and run the script inside the blender file.
It'll generate 6 images and stitch them together as godot standard for cubemaps, after it's generated you can export the image wherever you want to.
